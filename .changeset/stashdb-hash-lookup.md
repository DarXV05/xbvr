Add a "Search StashDB by hash" button to the "Match file to scene" dialog. It looks the file's oshash up on StashDB and shows what StashDB knows about it, along with any local scenes whose URL shares the same slug, so the file can be linked and assigned in one step. Previously an oshash lookup only ran during a volume rescan, and only for scenes already linked to StashDB.
